# 搜救小船系统 —— 软硬件工作平台说明

## 一、硬件工作平台

### 1.1 主控板
| 项目 | 规格 |
|------|------|
| 开发板 | 飞腾派（Phytium Pi）D2000/8 |
| CPU | Phytium D2000/8，ARM64架构，8核2.3GHz |
| 操作系统 | 飞腾Linux（基于Debian/Ubuntu的ARM64发行版） |
| 内存 | 8GB DDR4 |
| 存储 | 64GB eMMC + 可扩展SD卡 |

### 1.2 外设模块
| 模块 | 型号/接口 | 连接方式 |
|------|-----------|---------|
| 电机驱动板 | 双路PWM驱动板 | USB转串口 /dev/ttyUSB0 |
| GPS模块 | UART GPS模块（NMEA协议） | 串口 /dev/ttyAMA2 |
| 4G通信模块 | EC20-CNV（Quectel） | USB转串口 /dev/ttyUSB2 |
| 超声波传感器 | HC-SR04 | GPIO 450(TRIG) / 485(ECHO) |
| 舵机（雷达） | SG90/舵机 | GPIO 510 |
| 舵机（视觉） | SG90/舵机 | GPIO 445 |
| 摄像头 | USB摄像头 | USB接口 /dev/video0 |
| 电源开关 | 拨动开关 | GPIO 446 |

### 1.3 引脚分配表
| GPIO编号 | 功能 | 方向 | 说明 |
|----------|------|------|------|
| 446 | 电源开关 | 输入 | 低电平有效（拨下接地=ON） |
| 450 | 超声波TRIG | 输出 | 触发信号 |
| 485 | 超声波ECHO | 输入 | 回波信号 |
| 510 | 雷达舵机PWM | 输出 | 循环扫描用 |
| 445 | 视觉舵机PWM | 输出 | 定点转动用 |

### 1.4 串口分配表
| 设备文件 | 模块 | 波特率 | 数据格式 |
|----------|------|--------|---------|
| /dev/ttyUSB0 | 电机驱动板 | 115200 | 8N1 |
| /dev/ttyAMA2 | GPS模块 | 9600 | 8N1 |
| /dev/ttyUSB2 | EC20 4G模块 | 115200 | 8N1 |

## 四、编译说明

### 4.1 编译命令
```bash
# 编译整个项目
make

# 清理编译产物
make clean

# 运行
sudo ./boat_main
```

### 4.2 编译参数
```
CFLAGS  = -Wall -Wextra -pthread -I. -O2 -std=c99 -D_GNU_SOURCE
LDFLAGS = -pthread
```

### 4.3 运行要求
- 需要root权限（设置SCHED_FIFO实时线程优先级）
- 需要先安装Python依赖
- 需要下载YOLO模型

---

## 五、注意事项

1. **GPIO权限**：程序需要root权限操作GPIO sysfs接口
2. **串口权限**：/dev/ttyUSB* 和 /dev/ttyAMA* 需要读写权限
3. **实时调度**：非root用户运行时线程会自动降级为SCHED_OTHER
4. **YOLO模型**：首次运行vision.py会自动下载模型（需联网）
5. **摄像头**：确保/dev/video0可用，可能需要安装v4l2驱动
