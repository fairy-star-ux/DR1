# 软件平台说明

更新日期：2026-11-01。本说明针对当前 DR1M90 版本，仓库仅保留当前平台所需程序与构建资料。

## 1. 硬件与任务分工

| 部分 | 当前职责 | 接口 |
|---|---|---|
| DR1M90 PS / ARM64 Linux | Web、两电机命令、GPS 解析、拍照、WiFi | HTTP、USB、AXI GP0 |
| DR1M90 PL / FPGA | 三路 50 Hz 舵机 PWM、角度寄存器、扫描、LED | AXI GP0 → PWM 引脚 |
| 电机驱动板 | 接收 PWM 串口协议并驱动两个电机 | USB 转 TTL，默认 `/dev/ttyUSB0` |
| ATGM336H 系列 GPS | NMEA 输出 | USB 转 TTL，默认 `/dev/ttyUSB1`，9600 8N1 |
| USB 摄像头 | MJPEG 采集 | UVC，默认 `/dev/video0` |
| USB WiFi | AIC8800D80 | `aic_load_fw`、`aic8800_fdrv`、nl80211 |

三个舵机分别是摄像头水平、摄像头俯仰、超声波支架。当前没有接入超声波 Trig/Echo 测距。
电机控制走 Linux 串口驱动板；TD 中保留的电机输出口当前被禁用，不用于实际电机供电或控制。

## 2. 版本与工具

| 项目 | 已观察版本/事实 |
|---|---|
| 器件 | DR1M90GEG400，速度等级 -2 |
| TD | 界面 Anlogic TD Release 2026.1 SP2；工程标识 6.2.200067 |
| FD | 使用既有 FD 2026.1 系列生成 BSP/FSBL；跨版本需重新导出硬件平台并验证 |
| Linux | 板上 `6.1.111-rt42 #3`，aarch64 |
| 内核配置 | 快照 `linux/kernel/configs/linux.config`；`CONFIG_PREEMPT=y`，`CONFIG_PREEMPT_RT` 未启用 |
| 版本后缀 | 官方树 `localversion-rt` 为 `-rt42`，不等于启用了 PREEMPT_RT |
| 根文件系统 | Buildroot 2022.02.6，BusyBox init |
| 交叉编译器 | SDK Linaro GCC 7.5-2019.12，`aarch64-linux-gnu-gcc` 7.5.0 |
| 应用 | Python 3 标准库；V4L2 工具使用 C、Linux V4L2 API |
| 官方 Linux SDK | `uisrc-lab-anlogic`；源码/配置指纹见 `manifests/` |

当前镜像不使用 systemd，启动服务用 `/etc/init.d/S99boat-web`，不是 `systemctl`。
Web 不需要 Flask、OpenCV、ultralytics、pip 或 NPU；这些只出现在历史视觉代码中。
Linux `/dev/mem` 访问要求足够权限，当前服务以 root 运行。

## 3. 启动与持久化

```text
SD FAT 分区 BOOT.bin
  └─ FSBL → 本项目 system.bit 配置 PL → U-Boot
       └─ boot.scr → uImage.lz4 + system.dtb
            └─ /dev/mmcblk0p2 ext4 根文件系统
                 └─ BusyBox init
                     ├─ S35usb-serial
                     ├─ S40aic-wifi + SDK 的 S41dhcpcd
                     └─ S99boat-web
```

BitWriter 的 PROGRAM_SRAM 只用于临时联调。仅把独立 `.bit` 放进 SD 卡目录不会让现有 FSBL 自动加载；要重新打包 `BOOT.bin`。
SD 选定启动模式按硬件手册配置；不能凭“所有拨码 ON”推断启动源。

## 4. Linux 路径与配置

| 路径/环境变量 | 用途/默认值 |
|---|---|
| `/usr/local/bin/boat_web_server.py` | Web 主程序 |
| `/usr/local/bin/camera_capture` | AArch64 拍照程序 |
| `/etc/default/boat-web` | 服务设备路径与 MMIO 配置 |
| `WEB_HOST` / `WEB_PORT` | `0.0.0.0` / `8080` |
| `MOTOR_SERIAL_PORT` | `/dev/ttyUSB0`，115200 8N1 |
| `GPS_SERIAL_PORT` | `/dev/ttyUSB1`，9600 8N1 |
| `CAMERA_DEVICE` | `/dev/video0`，需确认是 Video Capture 节点 |
| `FPGA_SERVO_MMIO_BASE` | 匹配位流时 `0x80010000`；未配置则禁用舵机 API |
| `PHOTO_DIR` | `/var/lib/boat-web/photos` |
| `/var/log/boat-web.log` | 应用日志 |
| `/etc/wpa_supplicant.conf` | 私有 WiFi 配置，不能提交 Git |
| `/lib/modules/6.1.111-rt42/` | 与编译内核匹配的模块及 modules.dep |
| `/lib/firmware/aic8800D80/` | WiFi 固件 |

USB 串口的编号会受插拔顺序影响，不代表固定硬件身份。部署后先用 `dmesg` 与设备 symlink 核对，再改变量。
串口以外的 `/dev/ttyS0` 是 Linux 控制台；`ttyS1` 文件存在不代表该 UART 已启用或引出。
当前版本没有用 FPGA UART 直接接 GPS，不能按旧讨论把它当作已完成。

## 5. 已实现和未实现

| 功能 | 状态/限制 |
|---|---|
| 两电机 Web 控制、可调速度 | 已实现；通道 1、3；无网络失联自动停车或硬件看门狗 |
| GPS 展示 | 已实现；`available` 只代表串口打开，`fix` 才代表定位有效；NMEA 校验和未验证 |
| 实时预览、手动拍照与图库 | MJPEG 640×480，共享采集；手动照片持久保存，支持清空 |
| 云台两轴角度 | API 写 FPGA；上电默认 90°；无位置传感器反馈 |
| 超声波舵机 | 定角、启停、0–180°扫描；无测距数据 |
| WiFi | 已验证 nl80211 关联；仍保留之前驱动 WARN 的排查记录 |
| 人像/人脸/YOLO/NPU | 旧代码或设想，尚未纳入本版本部署 |
| 4G / OneNET / 自主避障 | 不在当前验收范围，历史代码单独保留且认证字段清空 |

Web 无登录认证且服务监听所有网卡，只在受控局域网联调；当前电机命令是保持式的，不要把网页关闭视为停车。

## 6. 一致性要求

同名 `6.1.111-rt42` 的两个内核仍可能配置不同。必须使用同一内核源码、配置、工具链与 Module.symvers 编译 CH341 和 AIC 模块，不能只看 `vermagic` 字符串相同。
更换位流后要核对 GP0 时钟、复位、地址译码和引脚。Web 返回成功只表示写入完成，不代表机械角度已测量。
