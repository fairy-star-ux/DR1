# 硬件接线

以下名称是 FPGA **封装管脚**，来自当前 `fpga/td/uisrc/04_pin/fpga_pin.adc`，不是排针序号。

| 顶层信号 | 封装管脚 | 用途 |
|---|---|---|
| I_sysclk | H16 | 板载 100 MHz 时钟，不接外设 |
| O_up_led[0] | T19 | 板载 LED |
| O_up_led[1] | R19 | 板载 LED |
| ultrasonic_servo_pwm | Y12 | 超声波支架舵机信号 |
| camera_pan_servo_pwm | T9 | 摄像头云台水平舵机信号 |
| camera_tilt_servo_pwm | T5 | 摄像头云台俯仰舵机信号 |
| motor_left_pwm | U9 | 保留/当前禁用，不接驱动板 |
| motor_right_pwm | V11 | 保留/当前禁用，不接驱动板 |
| motor_enable | U7 | 保留/当前禁用，不接驱动板 |

## 舵机

1. 先断开电源，按照板卡原理图找到 Y12、T9、T5 在扩展接口上的对应位置，不按照片猜排针编号。
2. 三个舵机信号线分别接上述三脚。
3. 舵机电源用满足具体舵机额定电压和堵转电流的电源；不要把 FPGA IO 当作供电端。
4. 舵机电源 GND 与板子 GND 共地；板上 3.3V IO 信号不能接 5V/12V 电源输出。
5. 若使用板上 5V 供电，先按硬件手册确认该端口额定电流和总负载；此前单机能动不能证明三舵机堵转时供电足够。
6. 先在 80–100° 小范围观察方向，再按机构限位决定是否允许 0–180°。

## 电机、GPS、摄像头、WiFi

- 电机驱动板通过 USB 转 TTL 连接 Linux，TX/RX 交叉、GND 共地；电机的两根动力线接驱动板输出，不直接接 FPGA。
- GPS 目前使用 USB 转 TTL；默认 GPS 9600 8N1，TTL 电平/模块电源以模块手册为准。
- 摄像头连接 USB Host，检查 `/dev/video0` 的实际 Capture 能力；`video1` 不一定是第二个摄像头。
- WiFi 使用 AIC8800D80 USB 网卡及匹配固件；不要用其他 AIC 型号的固件混装。
- 扩展坞曾有 `device descriptor read/64, error -71` 和断连记录。排查时先单设备直连，再逐个接回；Hub 已枚举不代表其后所有设备都稳定。
